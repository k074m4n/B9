Scope. B9 helps craft and bookkeep variations of text you write, for authorized testing on Gray Swan Arena. It never contacts any website, never auto-submits, and never guesses model identities (Arena Rules 3 & 4). Every tool works opened straight from file:// with the network unplugged; all data stays in your browser's local storage.
Shared system. Every tool shares one theme (shared/theme.css). The attempt-trackers (Facet, Salvo) run on one engine (shared/core.js) — identical variant queue, stats, export and keyboard loop (c copy, 1–4/0 log, u undo, j/k move). The workbench tools (Recon, Codec, Lens, Sieve, Dossier, Atlas) share lightweight plumbing (shared/kit.js). Dossier imports a Salvo/Facet JSON export, so the loop ends in a finished write-up.
