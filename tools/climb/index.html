Crescendo recipe

1. Enter the domain with a real, legitimate question.
2. Invest — ask a thoughtful follow-up, accept its answer so it commits.
3. Narrow one step; still legitimate.
4. Anchor to its own words ("you mentioned X — expand X in full").
5. Ask the goal as the obvious next sentence, not a new request.
↩ Hesitates? Back off one step, get a smaller yes, re-approach. Never re-issue the blunt ask (that hands it the refuse-moment).
